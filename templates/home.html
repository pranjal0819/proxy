Welcome to the Proxy Server!

This is a simple homepage for the Django app running on http://0.0.0.0:8000.

Using the Proxy Server

GET Request

        curl -X GET "http://0.0.0.0:8000/proxy?target_url=https://api.example.com/data"

POST Request

        curl -X POST "http://0.0.0.0:8000/proxy?target_url=https://api.example.com/data" \
        -H "Content-Type: application/json" \
        -d '{"key": "value"}'

PUT Request

        curl -X PUT "http://0.0.0.0:8000/proxy?target_url=https://api.example.com/data" \
        -H "Content-Type: application/json" \
        -d '{"key": "new_value"}'

DELETE Request

        curl -X DELETE "http://0.0.0.0:8000/proxy?target_url=https://api.example.com/data"
